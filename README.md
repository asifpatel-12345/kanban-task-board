# 📋 Interactive Kanban Task Board

A sleek, responsive, and lightweight **Drag-and-Drop Kanban Task Board** built using pure HTML5, CSS3, and modern Vanilla JavaScript. This application allows users to visually organize daily tasks, manage productivity workflows, and automatically save data locally.

## ✨ Features

- 🎯 **3-Column Workflow:** Organize tasks into *To Do*, *In Progress*, and *Completed*.
- 🖐️ **Native Drag & Drop:** Effortlessly drag cards between status columns.
- 💾 **Persistent Data:** Uses `localStorage` so tasks remain saved even after refreshing or closing the browser.
- 🎨 **Modern Dark UI:** Clean design with smooth color accents, responsive layout, and interactive card hover effects.
- 🔢 **Dynamic Counters:** Live updates on task counts per column.
- 🗑️ **Task Management:** Instant creation and one-click deletion of tasks.
